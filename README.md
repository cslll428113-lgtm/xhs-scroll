# 小红薯顺滑刷 · 鼠落

辅助在电脑端连续浏览小红书视频的浏览器扩展，当前版本 **0.5.1**，适用于支持 Manifest V3 的 Chrome / Edge。

## 功能

- 桌面置顶小窗刷视频，在小窗内直接切换，支持后台自动下一条。
- 收集推荐页、搜索页和用户主页当前已加载的视频卡片，通过滚轮、↑↓ 方向键或按钮切换。
- 支持自动下一条；阅读评论时保留当前视频循环播放。
- 可拖动悬浮窗，收起后保留上下条和 ↻ 换批按钮。
- 独立视频页与原首页分开，点击换批时重新加载独立页并建立新列表。
- 不主动滚动加载，不自动刷新原首页，不承诺每批视频数量。

## 在用户主页刷视频

在用户主页展开插件面板，等待页面已加载的视频被收集后点“开始”，即可在该主页的视频列表中切换，也可播放后开启小窗。
支持主页笔记链接和 SVG 播放标记；图文和作者资料链接不会作为视频加入。仍只收集页面已加载的内容，不自动下拉或刷新用户主页。
如果仍显示没有视频，点“查看诊断”后复制记录；新版本会记录卡片数量、识别到的视频卡片数量和有效链接数量，不记录主页地址、账号、标题或令牌。

## 小窗刷视频

先进入“独立刷视频”，播放一条视频后展开面板，点击 **小窗刷视频**。
小窗置顶于其他软件上方，可拖动和调整大小，支持上一条 / 暂停 / 下一条、静音、自动下一条，以及小窗内的滚轮和 ↑↓ 方向键。网页在后台时，小窗模式仍允许自动切换。

- 使用支持 `documentPictureInPicture` 的新版桌面 Chrome / Edge；不支持时会提示，不会替换成普通弹窗。
- 只使用网站原有的视频播放器，不复制下载链接或另外播放一份音频。切换前归还播放器，关闭小窗后恢复网页中的播放器；被网站移除的旧播放器会停止并清理。
- 保留小红书标签页。关闭、刷新或离开该页面会关闭小窗；“换一批”仍由用户主动点击，刷新后需再次点击“小窗刷视频”。
- 方向键仅在网页或小窗获得焦点时生效，不抢占其他工作软件的按键。
- 网站可能改变播放器行为；本版已通过本地模拟检查，真实小红书页面中的小窗连续播放仍需试用确认。

## 安装

1. [下载 0.5.1 安装包](downloads/xhs-scroll-v0.5.1.zip?raw=true)，下载后解压。
2. Edge 打开 `edge://extensions`；Chrome 打开 `chrome://extensions`。
3. 开启“开发人员模式”，点击“加载解压缩的扩展”，选择包含 `manifest.json` 的文件夹。
4. 打开小红书，使用面板里的“独立刷视频”；看完一批后点击 ↻ 换批。

## 更新已安装的扩展

将新版解压到固定的扩展文件夹，前往浏览器扩展管理页点击“重新加载”，然后刷新独立视频标签页以载入新脚本。GitHub 中的代码更新不会自动替换本地扩展。

## 测试与打包

本地检查需要 Node.js，打包需要 Python 3；不需要安装第三方依赖。

```sh
node --test tests/*.test.cjs
python3 scripts/package.py
```

Windows 上若 Python 命令名为 `python`，使用 `python scripts/package.py`。安装包生成于 `dist/xhs-scroll-v0.5.1.zip`，版本号自动从 manifest 读取。打包文件仅包含浏览器实际加载的脚本、图标及使用说明。

对外分享的安装包放在 `downloads/`，源码位于仓库根目录。后续发布时，将验证后的新安装包复制到 `downloads/` 并更新上面的下载链接。

`tests/card-click.browser.cjs` 是独立的浏览器检查，不包含在上述本地测试中。常规测试使用模拟页面，不能代替真实小红书环境的试用。

## 后续协作

后续修改以此仓库为准：先读取最新代码，再修改、验证并提交，同步更新版本号和 CHANGELOG。需要安装包时重新运行打包脚本；历史提交用于追踪修改和恢复旧版。

## 数据与边界

扩展使用 `storage` 权限保存偏好；诊断记录和页面队列保存在浏览器本地，不包含上传诊断记录的服务。网站本身的请求仍由小红书页面处理。请勿把账号、Cookie、令牌或个人诊断记录提交到仓库。

本项目为非官方个人辅助工具，与小红书官方无关联。当前基础功能已由使用者试用，仍可能受网站结构变化影响。
